# Website Portofolio

Halaman portofolio pribadi sederhana yang dibuat dengan **HTML** dan **CSS** (plus sedikit JavaScript untuk tahun otomatis di footer).

## Struktur File

```
index.html    -> struktur dan isi halaman
style.css     -> tampilan (warna, tata letak, responsif)
```

## Cara Menjalankan

1. Unduh atau clone repositori ini.
2. Buka file `index.html` langsung di browser.

Tidak perlu instalasi atau server khusus.

## Bagian Halaman

- **Hero** – nama, profesi, dan tombol navigasi
- **Tentang** – deskripsi diri dan data singkat
- **Skill** – teknologi yang dikuasai
- **Proyek** – daftar proyek
- **Kontak** – email dan media sosial

## Cara Mengubah Data

| Yang ingin diubah | Lokasi |
| --- | --- |
| Nama, NIM, jurusan | `index.html` bagian Hero dan Tentang |
| Daftar skill | `index.html` bagian `#skill` |
| Daftar proyek | `index.html` bagian `#proyek` |
| Email / sosial media | `index.html` bagian `#kontak` |
| Warna utama | `style.css`, variabel `--warna-utama` |
